03 / How privacy works

Private by design.

Requests are stored privately and access is limited to the owner. There is no public order list to browse.

01

Encrypted in transit

Your request is encrypted in transit using HTTPS, so it stays protected as it travels to us.

02

Protected storage

Requests are stored privately. Only the owner can view and manage incoming requests.

03

Owner access only

Only the owner can decrypt and view your request. No shared credentials are used.

Option A / Standard security

HTTPS + protected storage

Use TLS, server-side access control, a single admin login with strong 2FA, and KMS-backed encryption for sensitive fields at rest.

Option B / True E2EE

Client-side encryption

Encrypt form data in the browser using the owner’s public key. Only the owner’s private key can decrypt it, so the server cannot read the content.
